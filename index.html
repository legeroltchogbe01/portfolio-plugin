Exporter

Téléchargez votre portfolio sous forme de site prêt à publier.

Votre site en un fichier ZIP

Il contient index.html, styles.css, script.js et le dossier images/.

Mettre le site en ligne

  1. GitHub Pages — créez un dépôt, déposez le contenu du ZIP (Add file → Upload files), puis activez Settings → Pages sur la branche main.
  2. Netlify — glissez le dossier décompressé sur app.netlify.com/drop.
  3. Vercel — importez le dossier comme projet statique.
